# Watu Credit SQL Assessment Project

## 📌 Project Structure
- `database/create_watu_credit.sql` → Creates the database and tables
- `data/insert_data.sql` → Inserts sample data into tables
- `queries/assessment_queries.sql` → Contains SQL solutions to assessment questions
- `snapshots/` → Screenshots of successful query outputs

## 📊 Tables
- **client** → Stores client personal details
- **vehicle** → Stores vehicle details
- **loan** → Stores loan details linking clients and vehicles

## 📝 Assessment Questions
1. **Find all clients named Paul and older than 25.**
   - Compute their age.
   - Order by age from oldest to youngest.
2. **Add number of loans per client** to query 1.
3. **Filter vehicles by engine size** (100cc, 125cc, 150cc).
4. **Total principal amount** per client full name and per vehicle make.
5. **Chronological order of loans** per client with loan sequence number.
